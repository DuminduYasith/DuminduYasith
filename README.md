## 👋 About Me

I’m **Dumindu Yasith**, an undergraduate student in **Information Technology and Management** at the **University of Moratuwa**.

I like building useful things across **software** and **embedded systems**. My work includes a university project for an **automated piano-playing mechanism** using **solenoids, ESP32, V rails, stepper motors, PCBs, Arduino Uno,** and a companion **web app**.

I also built a **bank account system in C** with features like:

* account creation
* searching accounts
* balance viewing
* transaction history
* money transfer updates using arrays

Right now, I am working on my **second-year software development project** with:
**NestJS, Python, SQL, Docker,** and related tools.
